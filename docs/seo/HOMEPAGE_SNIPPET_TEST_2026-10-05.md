# Homepage organic snippet test — 2026-10-05

## Why this test exists

Search Console for 2026-09-27 through 2026-10-03 reported 100 homepage impressions, 0 clicks, 0% CTR and average position 3.7. The query `commercial cleaning` accounted for 77 impressions. This meets the project's existing gate for one controlled title and meta-description test.

## Variant

- Title: `Commercial Cleaning in Utah | PRMB Cleaning`
- Meta description: `Commercial, office and residential cleaning in Salt Lake City, Provo, Ogden and Park City. Call or text PRMB Cleaning at (385) 314-9098.`

No visible layout, content hierarchy, URL, schema, canonical or service claim changes in this experiment.

## Measurement rules

1. Use Search Console page filter `https://prmbcleaning.com/` and compare equal 14-day periods after Google has recrawled the page.
2. Primary metric: clicks and CTR for non-brand commercial-cleaning queries.
3. Guardrail metrics: impressions, average position and branded-query clicks.
4. Do not change the homepage title or meta description again during the first 14 days unless there is a factual error.
5. Keep the variant only if CTR improves without a material loss of relevant impressions or position. Otherwise restore the previous snippet or test a materially different factual message.

The snippet shown by Google may differ from these fields; this is a measured hypothesis, not a ranking guarantee.
